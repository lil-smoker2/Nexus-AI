# PHASE 11 — Autonomous software engineering agent

## Objective

Build the full Kilo Code-like agent using the planning, TODO, tool and MCP infrastructure already developed.

### Step 11.1 — Workspace manager

Implement:

- Workspace creation.
- Workspace registration.
- Project scanning.
- File tree extraction.
- Language detection.
- Dependency detection.
- Project configuration discovery.
- Git repository detection.

### Step 11.2 — Code context engine

Implement:

- File retrieval.
- Symbol search.
- Code search.
- Project indexing.
- Relevant file selection.
- Context prioritization.
- Context size management.
- Change tracking.

### Step 11.3 — Code operations

Implement:

- File creation.
- File editing.
- Structured patches.
- File deletion with approval.
- Rename operations.
- Code generation.
- Code formatting.
- Refactoring.

### Step 11.4 — Terminal execution

Allow the coding agent to:

- Run project commands.
- Install dependencies.
- Execute tests.
- Start development servers.
- Inspect output.
- Diagnose errors.

Use controlled execution environments and approval policies.

### Step 11.5 — Autonomous development cycle

For each development task:

1. Understand the requirements.
2. Inspect the project.
3. Build an implementation plan.
4. Create TODOs.
5. Identify required tools.
6. Execute the first task.
7. Inspect the result.
8. Modify code where needed.
9. Run tests.
10. Diagnose failures.
11. Replan when required.
12. Continue until completion.
13. Produce a report.

### Step 11.6 — Build project awareness

Support:

- Python.
- JavaScript.
- TypeScript.
- React.
- FastAPI.
- Django.
- SQL.
- HTML.
- CSS.
- Other languages as adapters and tooling are added.

### Step 11.7 — Build Git integration

Implement:

- Status inspection.
- Diff inspection.
- Branch management.
- Commit preparation.
- Commit creation with approval policies.
- Change review.
- Rollback of supported operations.

### Step 11.8 — Build testing and debugging

Implement:

- Test discovery.
- Test execution.
- Error extraction.
- Stack trace analysis.
- Failure classification.
- Suggested fixes.
- Regression testing.

### Step 11.9 — Build project memory

Store:

- Project purpose.
- Architecture.
- Technology stack.
- Important files.
- Previous decisions.
- Outstanding tasks.
- Known bugs.
- Build instructions.

### Step 11.10 — Test complete development workflows

Examples:

- Create a Flask application.
- Create a Django application.
- Build a REST API.
- Add database integration.
- Diagnose a failed build.
- Implement authentication.
- Run automated tests.

**Completion criteria:** The coding agent can autonomously develop, modify, test and verify real software projects.
