# NEXUS AI

Autonomous multi-agent desktop AI application.

## Roadmap

- `overview` — Master Software Development Roadmap index and cross-phase guidance (17 phases)
- `docs/roadmap/` — Detailed roadmap, split into one file per phase
- `NEXUS_AI_Revised_Master_Roadmap.md` — Implementation-oriented specification (17 phases)
- `docs/` — Product requirements, technical architecture, and UI specifications

## Frontend direction

The primary interaction is a companion chat workspace with a persistent navigation rail, a dedicated avatar stage, a central conversation, and an optional context panel for user-facing activity and memory controls. See [the chat experience specification](docs/chat-experience.md) and [the visual preview](docs/nexus-ai-chat-preview.svg). The preview is a design reference, not a claim that every depicted interaction is already implemented.

## Development approach

Modular, incremental, test-driven, security-first. Build one reliable layer at a time, test it, document it, then continue.

## Initial platform

Arch Linux, GNOME, Wayland.
